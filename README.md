# 回廊种菜系统（SillyTavern 扩展）

在角色扮演中追踪玩家所处的「副本」：按对话轮数推算阶段和时间，在每次生成前把副本进度和本轮应发生的事件注入提示词，并提供一个玩家面板（系统、设置、调试；副本资料显示在系统页下方）。

当前为第一期。副API、积分账本、直播、下注属于后续各期，代码里只留了位置（`src/reserved/`），没有实现。

## 安装

1. 打开 SillyTavern → 顶部「扩展」（积木图标）→「安装扩展」。
2. 填入本仓库地址：`https://github.com/xiaxiii/M-bius-strip`，确认安装。
3. 刷新页面。右侧出现可拖动的悬浮球；魔棒菜单和「扩展」设置列表里都会出现「回廊种菜系统」（列表里那一栏可以打开面板、开关悬浮球、把悬浮球放回默认位置）。

仓库里已经带有打包好的 `dist/index.js`，不需要自己构建。

## 支持的 ST 版本

- **实测可用：1.19.0**（release 分支）。开发时按这个版本的源码核对了接口，并在本地实际运行 ST 1.19.0 做了端到端测试（入场、轮次、滑动、重新生成、删楼、跳过、阶段切换、结算、世界书被暗号触发、quiet 生成不注入）。
- 更早的版本没有测试，不保证能用。

## 使用

- AI 输出副本简报（如「副本简报 - 钟楼」）后，会弹出「检测到进入《钟楼》，是否启用？」。未收录的副本名会使用通用副本包（名称、等级、目标、时限从简报读取）。
- 没有简报行也能认出已收录的副本：`<副本>` 里的「副本名：X」、正文里的「本次副本《X》」「此次副本《X》」、`<状态栏>` 地点一行的「副本《X》」，以及副本包自带的识别规则（如喜宴的「6=5+1」）。只提到副本名的闲聊不会触发。
- 开场白也会检查：新建聊天、加载或切换聊天、左右滑动切换开场白时，都会检查第一条 AI 消息，识别到就弹窗，确认后以开场白为第1轮。
- 点了「取消」的那条消息不会再问（重新生成后仍在同一楼也不问）；之后更晚的消息再出现信号时会再问一次。
- 也可以在面板「系统」页手动选择副本：以最新一条 AI 回复作为第1轮。
- 用户消息里写「跳到日落」「睡到天亮」等，会弹出确认；也可以在系统页点「跳过」直接跳到本阶段结束。
- 在副本中，每次生成前注入三块内容（都在聊天内，系统角色）：
  - `rlzc_token`（深度4，参与世界书扫描）：暗号，如 `【副本进行中：钟楼】`，用于触发世界书条目；
  - `rlzc_progress`（深度4）：副本进度；
  - `rlzc_turn`（深度0）：本轮后台事件与指令。
  深度可在设置页修改。回廊中（没有进行中的副本）不注入任何内容；quiet、impersonate 生成也不注入。
- `<阶段切换>`、`<副本结算>`、`<副本>`、`<角色登记>`、`<积分变动>` 只在显示时隐藏，消息原文不会被改动。

### 副本信息显示位置

设置页可选：

- **扩展面板**（默认）：正文里隐藏 `<副本>`，时限、进度条、任务、ps 显示在系统页。
- **正文状态栏**：正文里保留 `<副本>`（交给你角色卡里的正则渲染），系统页不再显示时限、进度条、任务、ps。其余标签照常隐藏，副本资料等不受影响。

切换后已经显示的消息会立即按新设置重新显示。

### `<副本>` 核对

无论选哪种显示位置，扩展都会读取 `<副本>` 原文做核对。核对只通过注入和调试页进行，不改动消息原文；结果每次从聊天记录重新计算，删楼、滑动后自动更新。

| 核对 | 处理 |
|---|---|
| 副本中某轮 AI 回复缺少 `<副本>`（入场简报本身除外） | 下一轮注入「上一轮缺少<副本>面板，本轮必须完整输出」，调试页记一条 |
| 进度条：入场后第一次出现的面板必须为0 | 还没出现过面板时注入「本轮<副本>的进度条写0」；不为0时调试页警告 |
| 进度条：数值须在 0–100 | 超出时调试页警告 |
| 进度条：比上一轮低 | 调试页警告，不自动纠正 |
| 时限（副本包有轮数表时） | 每轮在本轮指令末尾注入时限应写的文字（见下文）；AI 写的与该楼快照里记录的注入值不一致时，调试页警告并把该楼标黄 |

进度条可以写成 `40%`、`40/100`、`2/5`、纯数字，或 `■■□□□` 这样的方块。

### 内置副本包

| 副本 | 等级 | 轮数上限 | 计时 | 截止 |
|---|---|---|---|---|
| 钟楼 | S | 白天72、夜晚28 ×3（300）；命案后调查50、审判50 | 钟时（塔内无钟） | 至第四日日出（调查起：至审判结束） |
| 污名 | B | 常规60 + 定稿20（80） | 倒计时，每轮3分钟，共4小时 | 至收播（关闭直播） |
| 喜宴 | D | 160 | 倒计时，每轮3分钟，共8小时 | 至天亮 |
| 游戏 | C | 90 | 倒计时，每轮8分钟，共12小时 | 至结算 |
| 考试 | A | 100 | 倒计时，每轮3分钟，共5小时 | 至考试结束 |
| 境界游乐园 | A | 无 | 不计时，不注入时限 | — |

### 时限与轮数

一轮 = {{user}}发言 + AI回复；入场那条简报算第1轮。轮数是防拖延的硬底线，剩余时间和轮数任一用尽即时限到达。详细规则见 CLAUDE.md 第12节。

- **剩余X/Y轮**：Y = 当前阶段链上所有阶段的上限之和，X = 即将生成这一轮之后还剩的轮数（钟楼第一日第2轮：298/300）。只写进进度块给AI看，状态栏不写轮数。系统页的「最多剩余轮次」显示这一轮结束后的剩余数（入场第1轮后 299/300），比注入给AI的多一轮，属正常；叫「最多」是因为剧情时间可能先用完。
- **倒计时副本**：约剩时间 = X × 每轮分钟；如果上一轮AI在 `<副本>` 里写的约剩更少，就用「那个值 − 每轮分钟」，只减不增。本轮指令末尾注入「本轮<副本>的时限一栏写：约剩7小时54分/8小时。……」，AI 可以写得更少，不能更多，总时长照抄。
- **钟楼**：注入「至第四日日出·剩余N夜」，命案后「钟楼停摆·调查中」「钟楼停摆·审判中」，要求照抄。
- **未收录的副本（通用副本包）**：从简报「时限：」读总时长；轮数上限用「（最多N轮）」，没有就按等级默认值（D 70｜C 90｜B 110｜A 135｜S 200，设置页可改，入场时确定）；每轮分钟 = 总时长 ÷ 轮数（四舍五入）。总时长照简报写（如「约剩9小时47分/10小时」），约剩按剩余轮数比例折算。读不到总时长时只计轮，不注入约剩时间。
- 简报是五行（副本名、人数、等级、时限、简报），没有「目标」行是正常的。

副本包字段：包级 `deadline` 与阶段级 `deadline`（截止条件）；`time.type` 为 `clock`（钟时）、`countdown`（倒计时，`minutesPerRound`）或 `none`。

### 副API（记录员）

副API是另请一个AI当记录员：副本进行中，每条新的AI回复生成后调用一次，读正文、整理状态，不写剧情。一次调用同时做三件事：核对本轮注入的后台事件有没有写出来；更新隐藏状态（钟楼有6个字段，其他副本是一段不超过150字的概况）；预判下一轮带条件的事件条件是否仍成立。回廊中不调用，「继续」不调用。

- 整理结果存在这一楼的 `chat[i].extra.rlzc.sub`；当前状态取最近一条带结果的楼，删楼、滑动后自动回滚。
- 下一轮注入 `rlzc_state`（［副本状态·仅供AI］）；预判「条件不成立」的事件不注入，调试页记一条；判为「没写出来」的事件在调试页标黄。
- 系统页只显示一行「副本记录：已更新（第N轮）」或「第N轮状态未更新」，隐藏状态本身只在调试页看。

#### 怎么设置（二选一，或用酒馆连接配置）

打开面板 →「设置」→「副API」卡，把「来源」从「关闭」改成下面其中一种：

**跟随主API（最简单）**
1. 「来源」选「跟随主API」。
2. 完成。记录员会用你现在聊天用的同一个模型、同一个密钥。
3. 注意：每轮会多用一次你的主模型，费用和聊天一样算。

**独立接口（用另一个更便宜的模型当记录员）**
1. 「来源」选「独立接口」，点「新建」，给这个接口起个名字（比如「便宜模型」）。
2. 「地址」填接口服务商给你的地址，通常以 `/v1` 结尾（例：`https://api.xxx.com/v1`）。
3. 「密钥」填服务商给你的 API Key（以 `sk-` 开头的那一串）。输入后显示为圆点，点「显示」可以看。
4. 点「测试连接」。显示「连接成功」后，「模型」会变成下拉框，选一个模型就行。
5. 可以建好几条预设，用下拉框切换；关掉酒馆再打开也都在，每条预设记得自己选过的模型。

**使用酒馆连接配置**：如果你已经在酒馆顶部「API 连接」里保存过连接配置，「来源」选「使用酒馆连接配置」，再选一个配置即可。

其他开关：
- **省钱模式**（默认关）：只在本轮有后台事件、或下一轮有带条件的事件时才调用。
- **等待整理**（默认开）：生成下一轮前先等记录员整理完，发送按钮旁会显示「整理中…」。关掉就不等，但主AI可能拿到晚一轮的状态。
- **超时**：默认60秒。

失败时会自动重试2次；还不行就弹窗说明原因（超时 / 密钥无效 / 额度不足 / 返回格式不对 / 其他），可以选「重试」「换一个接口」（弹窗里直接选别的预设）或「这轮先跳过」（沿用上一轮状态）。关掉「等待整理」时只弹提示、不挡生成。

密钥保存在本机的酒馆设置里。分享设置文件或截图时，请注意不要带出密钥。

### 数据存放位置

| 数据 | 位置 |
|---|---|
| 副本会话 | 聊天元数据 `chatMetadata.rlzc` |
| 备忘录（旧数据，页签已删除，原样保留） | 聊天元数据 `chatMetadata.rlzc_memo` |
| 每楼快照（仅调试显示用） | `chat[i].extra.rlzc` |
| 副API整理结果（每楼） | `chat[i].extra.rlzc.sub` |
| 设置、导入的自定义副本包、副API接口预设（含密钥） | `extensionSettings.rlzc` |

状态永远由聊天记录重放得出，不存累加计数器，所以删楼、滑动、编辑之后轮次会自动恢复正确。

## 手工检查清单

安装后请在酒馆里逐项确认：

1. 安装并刷新后，悬浮球出现，可以拖动；魔棒菜单和「扩展」设置列表里都有「回廊种菜系统」。
2. 面板三个页签（系统、设置、调试）都能切换；调试页会先弹二次确认。
3. 让 AI 输出钟楼简报后，弹出「检测到进入《钟楼》，是否启用？」，确认后系统页显示钟楼、第一日·白天、1/72。
4. 连续聊几轮，系统页轮次逐轮 +1，钟时每轮加5分钟。
5. 重新生成、左右滑动最后一条回复，轮次不变。
6. 删除最后一条 AI 回复，轮次减一。
7. 打开提示词查看器（Prompt Itemization），能看到进度、本轮指令、暗号三块注入。
8. 钟楼世界书中以暗号为关键词的条目被触发。
9. 系统页点「跳过」或发送「跳到日落」并确认后，下一轮直接快进，注入里出现快进说明与合并的事件。
10. 设置里保存两条副API接口预设，切换后关掉酒馆再打开，两条都在、选中的还是上次那条。
11. 故意把密钥填错，出现失败弹窗；「重试」「换一个接口」「这轮先跳过」三个按钮都有效。
12. 钟楼跑几轮，调试页能看到每轮的事件核对（✓ / ✗ / –）和隐藏状态。

## 开发

```bash
npm install
npm test        # vitest 单元测试（重放、识别、事件选择、注入）
npm run build   # 类型检查 + 打包到 dist/index.js
```

目录结构：

```
manifest.json          ST 扩展清单（generate_interceptor = rlzcInterceptor）
src/index.ts           入口：注册拦截器、事件、挂载界面
src/app.ts             运行时状态、ST 事件处理、手动操作
src/st/                对 SillyTavern.getContext() 的薄封装
src/packs/             副本包类型、加载与校验、内置包（builtin/ 为 packs/ 的原样拷贝）
src/core/replay.ts     从聊天记录重放出当前状态（纯函数）
src/core/detector.ts   识别简报、标签、跳过关键词
src/core/injector.ts   组装注入内容
src/core/hideTags.ts   正文显示时隐藏机器标签
src/ui/                Vue 组件（Shadow DOM 内）
src/reserved/          第二到第四期的占位接口
tests/                 vitest
```

修改 `packs/` 下的副本包后，请同步拷贝到 `src/packs/builtin/` 再重新打包。
