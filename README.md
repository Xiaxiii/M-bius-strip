# 回廊种菜系统

SillyTavern 扩展，配合角色卡《∞》使用。

它在后台替 AI 记账：进了哪个副本、走到第几轮、还剩多少时间、这一轮该发生什么事、积分还剩多少。每次生成前，把这些告诉 AI，让长篇跑团不跑偏、不忘事。另外附带直播和黑市两个玩法。

## 安装

1. SillyTavern 顶部「扩展」（积木图标）→「安装扩展」。
2. 填入 `https://github.com/xiaxiii/M-bius-strip`，确认。
3. 刷新页面，右侧出现可拖动的悬浮球，点它打开面板。

更新：在「扩展」→「管理扩展」里点更新即可，无需自行构建。

## 功能

### 副本追踪（核心）

- **自动识别入场**：AI 写出「副本简报 - 钟楼」这类简报时，页面右上角出现一张「检测到副本」小卡片：点「进入」启用，「不是」这条消息不再问，「✕」这次先不处理；卡片不挡操作。开场白里的简报也能识别，左右滑动开场白时会重新判断。没收录的副本会自动套用通用规则，名称、等级、时限从简报里读。
- **轮次与时限**：一轮 = 你说一句 + AI 回一句。扩展按轮数推算阶段、钟点和剩余时间，到点自动日落、日出、结束。
- **事件安排**：副本包里写好的剧情事件，到了对应的轮次就提醒 AI 写出来。
- **快进**：在消息里写「跳到日落」「睡到天亮」，或在面板点「跳过」，确认后直接快进；途中有必须由你决定的事会停下。
- **自动回滚**：所有状态都从聊天记录重新推算。删楼、重新生成、左右滑动后，轮次、积分、直播都会自动恢复正确。

### 副本事件检测（可选）

每轮让另一个 AI 读一遍正文，核对该发生的事件有没有写出来，并记下副本的隐藏状态（比如曲柄在谁手里）。需要在设置里选一个接口，会多花一次调用。直播的精彩度、黑市的事件盘也靠它判定。

### 积分账本

- 积分由扩展记账，AI 在状态栏照抄。
- 副本结算的奖励和失败扣分，按积分表自动计算；其他收支由 AI 用 `<积分变动>` 标签报账。
- 余额跌破斩杀线时自动标记「待清算」，下一场是清算副本，通关后才解除。
- 账本页可以看到每一笔流水和记完后的余额。积分、等级不对时，在设置里的「账户校正」修改。

### 直播

- 进副本时可以选择开播，回廊里随时开播、下播。
- 每轮有观众弹幕和打赏。打赏系统抽成 40%，其余计入积分；副本里收到的打赏出副本前不能花，在副本里死亡会全部撤回。
- 弹幕来自本地弹幕池，也可以让 AI 按正文现编。
- 直播画面显示在角色卡的状态栏里（需要配套的状态栏正则），扩展面板里只有直播设置。

### 黑市

- **盘口**：押你自己这一局的故事，每局随机开 2–5 个盘，包括结局、评价、副本专属事件，以及庄家现场出的怪题。入场后开盘，第 1 轮结束封盘。
- **票夹**：你的赌票，开奖后盖「兑 / 废 / 退」章。
- **赌坊**：即开即结的小游戏，每次回到回廊换两张桌。默认只在回廊营业。
- 庄家抽水 20%，单注有上限，长期玩一定是亏的。

## 面板

| 页签 | 内容 |
|---|---|
| 系统 | 当前副本、阶段、轮次、剩余时间；副本资料（规则、地图等）；回廊中可手动选择副本 |
| 账本 | 当前积分、等级、斩杀线、待清算；收支流水 |
| 黑市 | 盘口、票夹、赌坊 |
| 设置 | 见下表 |
| 调试 | 每一楼的注入内容、事件核对、直播与盘口数据（只读，需在设置里打开调试模式才能修改） |

## 设置

| 设置 | 作用 |
|---|---|
| 副本信息显示位置 | 副本的时限、任务显示在扩展面板，还是交给正文里的状态栏 |
| 账户校正 | 修改初始积分、手动记一笔、校正等级和位格 |
| 注入深度 | 每段提示插在聊天记录的哪个位置，一般不用改 |
| 副本事件检测 | 关闭、跟随主 API，或另设一个便宜的 API |
| 直播 | 弹幕来源、AI 生成频率、是否把弹幕告诉 AI |
| 通用副本默认轮数上限 | 没收录的副本按等级取多少轮 |
| 自定义副本包 | 导入自己写的副本包（JSON） |

## 配合角色卡

扩展需要 AI 按约定格式输出以下内容，《回廊》角色卡的世界书里已经写好：

- 入场简报：`「副本简报 - 副本名」`，下面几行写人数、等级、时限。
- `<副本>`：副本面板（时限、进度条、任务）。
- `<状态栏>`：{{user}}的积分、等级、在场角色等。
- `<副本结算>`、`<阶段切换>`、`<角色登记>`、`<积分变动>`：机器标签，扩展读取后只从显示中隐藏，不改动消息原文。

## 注入给 AI 的内容

每次生成前，扩展往提示词里加几段只给 AI 看的说明（玩家看不到，quiet 和 impersonate 生成不加）：

| 内容 | 默认深度 | 何时出现 |
|---|---|---|
| 副本暗号（触发世界书里这个副本的条目） | 4 | 副本中 |
| 副本进度：阶段、轮次、时限、已发生事件 | 4 | 副本中 |
| 本轮指令：本轮事件、时限写法 | 0 | 副本中 |
| 副本状态（开启事件检测时） | 4 | 副本中 |
| 账户：积分与清算状态 | 4 | 回廊和副本中 |
| 直播：在看人数与最近弹幕（默认关） | 4 | 直播中 |

深度 0 = 紧挨着最新消息，数字越大越靠前。所有存储字段都以 `rlzc`（回廊种菜）开头。

## 兼容性

- 在 SillyTavern **1.19.0** 上实测可用，桌面和手机宽度都测过；更早的版本不保证。
- 与柏宝书、酒馆助手同时启用测试通过。被记忆类扩展 `/hide` 隐藏的旧楼层照常计轮。
- 自设 API 的密钥只存在本机的酒馆设置里。分享设置文件或截图时注意别带出密钥。
